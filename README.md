## EMBASSY

### The policy layer between an AI agent and the real world.

Autonomous agents shouldn't blindly execute every action.

**Embassy** introduces a policy and risk layer that evaluates actions before execution.

     ↓
┌──────────┐
│ APPROVAL │
└────┬─────┘
     ↓
